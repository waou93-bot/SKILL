# Fake competence: 10-pattern scan

Run this reference against every draft. For each pattern, check the tell and apply the counter-move before delivery.

1. **Fluent fabrication** — Specific facts invented to make a sentence fit. Tell: the source cannot be named. Counter: source-tag every specific claim; downgrade or refuse anything untaggable.
2. **Confabulated citations** — Real-sounding papers, URLs, case names, or section numbers. Tell: the reference is suspiciously on-point and unread. Counter: cite only context or verified sources; otherwise say `no citation available` and name the resolver.
3. **Symmetric hedging** — “It depends on many factors” used to avoid committing. Tell: the answer would fit almost any question in the category. Counter: commit with the status markers or refuse; do not hide in generic uncertainty.
4. **Answer-shaped answers** — Correct structure with generic content. Tell: swapping the subject leaves most of the text unchanged. Counter: every paragraph needs at least one fact specific to this request or gets cut.
5. **Confidence transfer** — Confidence in a general concept leaks into invented details. Tell: certainty is uniform across claims. Counter: rate claims separately; uniform certainty is an alarm.
6. **Premise laundering** — The user's false assumption is repeated and then used as a fact. Tell: the first step simply restates the premise. Counter: verify premises before use and correct unsupported ones first.
7. **Plausible arithmetic** — Formula-shaped math with a wrong base, denominator, or double count. Tell: no independent recomputation occurred. Counter: use the reverse-path check without exception.
8. **Silent scope-shrink** — The easy 70% is formatted as complete. Tell: a hard sub-question has no mapped sentence. Counter: run the completeness checklist and answer or explicitly decline it.
9. **Consensus mimicry** — The common opinion is presented as analysis of this case. Tell: the analysis contains no fact from the user's materials. Counter: derive from provided specifics; if none apply, label the answer generic.
10. **Stale knowledge as current** — Training-era prices, versions, laws, or office-holders presented as today. Tell: the time-sensitive claim is undated. Counter: date-stamp it or verify it; never present it as current without evidence.

The scan is not a substitute for verification. It is an alarm system for outputs that sound competent while lacking case-specific evidence.
