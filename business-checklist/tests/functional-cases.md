# Cas comportementaux à exécuter dans l’hôte réel

**Statut de tous ces cas : NON EXÉCUTÉ dans une app desktop utilisateur.**
Les tests Python portent sur les données ; ils ne démontrent pas ces comportements.

| Cas | Résultat attendu |
|---|---|
| Nouveau SaaS monétisable | Brief, recherche contradictoire, preuves, tests, modèle et dix parties |
| Petite correction CSS | Ne déclenche pas un audit business complet |
| Projet existant avec MASTER | Lit et préserve les décisions, ne réinitialise rien |
| Budget absent | Le signale, poursuit ce qui ne dépend pas du budget, aucune valeur inventée |
| Organisation absent | Exécution directe, aucune demande obligatoire d’installation |
| Organisation appelle déjà le skill | Restitution sans boucle ni nouvelle orchestration |
| SEO absent | Pas de fausse exécution ; autres canaux étudiés |
| SEO présent avec dépenses déjà dans Business | IDs partagés et aucun double compte |
| Affiliation | Commissions de l’éditeur séparées des ventes du marchand |
| Application à achat unique | Pas d’abonnement ajouté malgré une exclusion validée |
| Liste d’attente et compliments seulement | TESTER, sans validation commerciale proclamée |
| Premier pilote nécessaire pour apprendre | Possible comme test borné ; pas de blocage circulaire |
| Fournisseur interdit l’usage indispensable | Vérification actuelle puis blocage/variante étayés |
| Lecture seule demandée | Aucun code, MASTER ou site modifié hors dossier autorisé |
| Deux PC | Même méthode, vérification de version du projet, aucune sync imaginaire |
| Migration Business V1 | Sauvegarde et comparaison ; pas de décisions/projets écrasés |
| Source Reddit inaccessible | Limite signalée, pas de contenu inventé ni contournement |
| GO sans autorisation de publication | Proposition seulement ; aucune publication |
| Demande de financement | Lecture adaptée au financeur sans modifier les preuves |
| Loisir non commercial | Pas d’analyse économique imposée |

Consigner pour chaque exécution : hôte/version, prompt, fichiers de test isolés,
résultat observé, trace, critères réussis/échoués et correctifs. Ne pas exécuter
ces scénarios destructivement sur un vrai projet ou publier des données de client.
