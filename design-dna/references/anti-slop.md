# Anti-Slop Gate

A design fails this gate if it looks like a plausible generic AI/template output rather than a deliberate project.

## Red flags to remove unless there is a strong project-specific reason

- centered hero with pill badge + huge generic headline + two buttons;
- purple/blue AI gradient as default identity;
- glassmorphism used decoratively;
- excessive rounded rectangles;
- 12 identical cards;
- automatic bento grids;
- feature grids before a real composition exists;
- fake dashboard screenshots;
- decorative 3D sphere/blob/orb;
- stock photos with no project-specific intent;
- random floating particles;
- glow on every interactive element;
- gradient text by default;
- copied startup illustrations;
- excessive icon-in-a-circle treatment;
- tiny eyebrow labels on every section;
- repeated "trusted by" logo strips without meaningful evidence;
- decorative animated backgrounds that fight the content;
- motion on every word;
- long loaders that exist only to feel cinematic;
- custom cursor that makes normal pointing harder;
- WebGL scene with no navigational, narrative or product value;
- arbitrary card radii and shadows inherited from a library;
- replacing approved project character with the defaults of a UI kit.

## Diagnostic questions

Before accepting a screen, ask:

1. Could this screen belong to 100 unrelated startups by changing the logo?
2. Is the composition driven by content or by prebuilt components?
3. Is there one clear visual idea?
4. Are the most noticeable effects serving meaning?
5. Does the screen still work if the decorative effects are removed?
6. Is the typography doing enough work?
7. Are there too many boxes where spacing and type could create hierarchy?
8. Is the project skin visible without making usability worse?

If the answer to #1 is yes, redesign.
