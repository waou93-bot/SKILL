# Motion DNA

## Preferred motion character

Motion should feel controlled, fluid, spatial, cinematic or material when the project calls for it.
It should never feel like a library demo.

Preferred families of motion:

- content reveal on scroll;
- masks and clipping reveals;
- subtle parallax;
- spatial continuity between states;
- full-screen chapter transitions;
- slow camera-like movement;
- selective kinetic typography;
- image reveals tied to reading rhythm;
- meaningful hover/magnetic behavior;
- 2.5D depth when cheaper and clearer than full 3D.

## Tool posture

GSAP / ScrollTrigger / Lenis / Codrops-style techniques are appropriate when they materially improve the experience.
Do not choose them because the project needs to look "advanced".

## Motion hierarchy

Use three levels:

1. **Micro** — hover, press, focus, selection, local feedback.
2. **Structural** — navigation changes, panel transitions, route/screen changes.
3. **Narrative** — scroll chapters, cinematic sequences, project signature transitions.

Not every project needs level 3.

## Rules

- One signature motion idea is better than many unrelated tricks.
- Preserve existing approved motion unless change is requested.
- Avoid simultaneous competing motions.
- Keep essential interactions immediate.
- Never hide basic navigation behind slow animation.
- Respect reduced motion.
- Use progressive enhancement.
- Offer low-power/no-WebGL fallback when relevant.

## Default intensity by project type

- Dense business/product software: low to medium.
- Marketing site: medium.
- Portfolio/editorial/culture: medium to high.
- Immersive/experimental: high only when justified.

Intensity is a ceiling, not a quota.
