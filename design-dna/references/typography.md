# Typography DNA

## Stable preferences

### Primary UI / body family

**Plus Jakarta Sans** is the preferred default when the project has no already-approved typeface.

Use it for:

- UI;
- body copy;
- navigation;
- buttons;
- forms;
- tables;
- product surfaces;
- dense application screens.

Default fallback stack:

```css
font-family: "Plus Jakarta Sans", Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
```

### Neutral fallback

**Inter** is an accepted neutral alternative, particularly for dense utilitarian interfaces.
Do not switch from Plus Jakarta Sans to Inter without a reason.

### Display direction

A recurring preferred direction is:

> strong condensed grotesque display + neutral sans-serif interface.

Do not force a condensed display face into every project.
Use it when a project needs stronger editorial, cultural, music, fashion, portfolio or campaign energy.

If the project already has an approved display typeface, preserve it.
If no display face has been approved, choose one deliberately for the project rather than importing a fashionable font automatically.

## Hierarchy rules

- Favor meaningful scale contrast.
- Large type should earn its size through composition.
- Avoid oversized centered headlines as a default hero formula.
- Tighten tracking on large display text when appropriate.
- Keep body measure readable.
- Prefer 2–4 meaningful text sizes on one screen over many almost-identical sizes.
- Buttons should not visually overpower headlines or navigation.
- Use weight and size before adding boxes, badges or decorative separators.

## Editorial behavior

Preferred techniques when conceptually justified:

- monumental titles;
- oversized section numbers;
- labels used as editorial anchors;
- type that participates in composition rather than sitting inside cards;
- controlled kinetic type;
- reveal masks;
- selective text/image overlap.

## Avoid

- font roulette;
- 3+ unrelated families on one product;
- trendy display fonts used without conceptual reason;
- fake luxury via ultra-thin serif + huge tracking by default;
- all-caps everywhere;
- tiny low-contrast body copy;
- generic centered SaaS typography hierarchy;
- automatically using a display font solely because the page needs to feel "premium".
