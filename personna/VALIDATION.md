# Vérification de la version 1.2.0 — 14 octobre 2026

17 tests unitaires exécutés, zéro échec : contrat de suite, budget, isolation,
PASS légitime de fixture, preuve/revue manquante, critères critiques, anciennes
traces refusées dans un nouveau run, contexte de revue obsolète, requête différente
malgré mise à jour de ses hashes, provenance modifiée après revue et JSON de
mauvaise structure. Ces fixtures sont synthétiques ; aucune inférence réelle.

Dix nouvelles sessions textuelles isolées ont été exécutées au format 2 : deux
tâches réelles (lecture de rapports d'installation historiques et contrat de liens
éditoriaux) et les trois adverses, sans/avec un profil de calibration documentaire.
Une revue séparée a examiné les 14 critères de fond ; les quatre assertions regex
passent aussi. Les deux variantes passent tous les cas : aucun gain causal n'est
démontré. Le profil fait 420 mots. Les essais 1.1 restent archivés sans conversion.

Ce profil est une calibration documentaire, pas une formation métier complète
par recherche et entretien. Modèle exact, coûts et paramètres non observés ;
traces de retours finaux, sans journal complet des outils. Aucune sécurité outillée
universelle certifiée. Ces preuves actuelles ont été admises par le contrôle
Studio 3.2 dans un dossier de test synthétique ; modifier le profil les rend STALE.

Le parcours recherche Reddit/GitHub puis entretien est conservé. Le programme
prépare, importe et évalue des preuves déclaratives ; il ne lance pas les agents,
ne garantit pas l’authenticité de l’hôte et n’exige aucun service payant additionnel.
