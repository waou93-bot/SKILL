# Design Quality Gates

A screen/project is not finished until all relevant gates pass.

## Gate 1 — Concept

- There is one clear visual idea.
- The idea belongs to this project.
- The design can be described without relying on generic adjectives.

## Gate 2 — Composition

- Hierarchy is obvious.
- Negative space is intentional.
- Repetition has rhythm, not monotony.
- The layout is not merely a sequence of component-library blocks.
- Commercial prompts support the content instead of stacking competing offers. Preserve an approved CTA position; a local promotion order is not a universal layout.

## Gate 3 — Typography

- Type establishes hierarchy before decorative containers do.
- The selected families fit the project's character.
- UI/body text remains highly readable.
- Display typography is deliberate, not fashionable filler.
- The skin explains UI/body and display choices; no font is selected solely from an old default or library preset. Approved project typography is preserved unless replacement is requested.
- Inspect real headings, paragraphs and comparison/table labels at mobile widths for word spacing, wrapping and hierarchy; a font name alone is not a typography pass.

## Gate 4 — Image quality

- No visibly weak asset is being hidden behind effects.
- Crops are intentional.
- Treatment is coherent.
- Real product/interface imagery is used when needed.
- Check visible product type, color, orientation and accessory proportions against the actual reference and label. If an image is illustrative/similar, identify it honestly rather than implying the exact product.

## Gate 5 — Motion

- Every noticeable animation has a reason.
- Motion intensity matches the surface.
- Basic interactions remain fast.
- Reduced-motion/fallback behavior exists where relevant.
- Inspect the full visible sequence for competing simultaneous animations, including hover and route return. State the intended intro/replay behavior for this project; do not impose one project's replay policy everywhere.

## Gate 6 — Anti-Slop

- No generic AI hero formula.
- No gratuitous glass/gradient/orb/bento treatment.
- No repeated identical card wall unless the content genuinely requires it.
- No library default look left unstyled.
- No purely decorative arrows on CTA buttons in default, hover, focus or animated states, including CSS pseudo-elements/SVG/icon components. Preserve functional direction/state controls such as disclosure chevrons, previous/next or external-destination indicators with a real purpose.

## Gate 7 — Technical quality

- Responsive behavior is designed, not merely stacked.
- Images are optimized.
- Layout does not shift unexpectedly.
- Accessibility is not destroyed by aesthetics.
- Heavy effects have fallbacks.
- Check disclosure closed/open states, focus, keyboard activation, state announcement and directional consistency. A functional chevron must not be removed because decorative CTA arrows are disallowed.

## Gate 8 — Authorship

Ask:

> Does this feel like a deliberate design decision, or merely a plausible generated answer?

If it only looks plausible, continue working.

Report each relevant gate as passed, failed or unverified with environment, state and evidence.
Without a rendered browser/device check, report source inspection only; do not claim mobile
wrapping, hover, motion or image proportions passed. An authored scenario is not an independent
evaluation. An audit does not authorize changing the site.
