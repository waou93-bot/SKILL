# Typography DNA

## Identity before defaults

Nicolas explicitly rejects typography that feels too standard. The decision to change is an
automatic, generic selection, not the mere presence of a familiar family. There is no universal
Plus Jakarta Sans default, Inter alternative or condensed-grotesque display direction.

Start with the project's approved typography and scope. Preserve approved families unless
replacement is requested. For a new direction, choose through the identity, language coverage,
content density, reading rhythm and actual rendering, not a component library's preset.

Record UI/body and display choices separately in PROJECT_SKIN, with the reason, approved
choices to preserve and fallback. A neutral body/UI face can be justified for forms, navigation
and dense tables while display type carries identity. Do not force every label into a novelty
font or replace approved type simply to make it unusual.

Compare candidates in the actual headings, labels, paragraphs and mobile comparisons. Check
accents/glyph coverage, available weights, loading/fallback shift, spacing and contrast. No
fixed font shortlist is required for a small correction; no external font installation is implied.

For Accord Raccord, the approved Georgia/Times headings and Plus Jakarta Sans body are a
local exception to a new-project choice, not an obsolete default to purge. Read its local
reference if available and preserve that pairing unless the user explicitly requests otherwise.

## Hierarchy rules

- Favor meaningful scale contrast.
- Large type should earn its size through composition.
- Avoid oversized centered headlines as a default hero formula.
- Tighten tracking on large display text when appropriate.
- Keep body measure readable.
- Prefer 2–4 meaningful text sizes on one screen over many almost-identical sizes.
- Buttons should not visually overpower headlines or navigation.
- Use weight and size before adding boxes, badges or decorative separators.
- Check word spacing, line-height and wrapping on narrow screens, especially comparisons/tables.
- Avoid forced line breaks that suit only one width, arbitrary letter breaks and compressed product labels; choose a readable mobile table treatment rather than shrinking text to fit.

## Editorial behavior

Preferred techniques when conceptually justified:

- monumental titles;
- oversized section numbers;
- labels used as editorial anchors;
- type that participates in composition rather than sitting inside cards;
- controlled kinetic type;
- reveal masks;
- selective text/image overlap.

## Avoid

- font roulette;
- 3+ unrelated families on one product;
- trendy display fonts used without conceptual reason;
- fake luxury via ultra-thin serif + huge tracking by default;
- all-caps everywhere;
- tiny low-contrast body copy;
- generic centered SaaS typography hierarchy;
- automatically using a display font solely because the page needs to feel "premium".
