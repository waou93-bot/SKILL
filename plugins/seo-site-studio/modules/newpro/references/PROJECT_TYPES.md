# Profils de projet

## Software

Retenir `software` quand les indices dominants sont du code, une configuration de build, des tests, un package manager ou une architecture d'execution. Ajouter :

- `07_ARCHITECTURE_TECHNIQUE.md` ;
- `08_CONVENTIONS_DE_CODE.md`.

Tranche par defaut : un parcours minimal complet avec un resultat visible et une preuve reproductible.

## Artistic

Retenir `artistic` quand les indices dominants sont des images, sons, videos, fichiers 3D, references visuelles ou dossiers de direction artistique sans socle logiciel significatif. Ajouter :

- `07_DIRECTION_ARTISTIQUE.md` ;
- `08_BIBLE_DES_ASSETS.md`.

Tranche par defaut : un artefact court, coherently directionne et presentable ou exportable.

## Hybrid

Retenir `hybrid` quand le projet depend de facon substantielle d'un logiciel et d'un resultat artistique ou media. Ajouter :

- `07_ARCHITECTURE_TECHNIQUE.md` ;
- `08_DIRECTION_ARTISTIQUE.md` ;
- `09_BIBLE_DES_ASSETS.md` ;
- `10_CONVENTIONS_DE_CODE.md`.

Tranche par defaut : une interaction logicielle complete qui produit ou manipule un resultat artistique visible.

## Cas indetermine

Ne pas choisir silencieusement. Poser une seule question de profil, proposer les preuves de la classification et laisser l'utilisateur corriger le profil avant le bootstrap.
