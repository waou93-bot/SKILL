# Newsite SEO

Système de réalisation de sites à partir d'une niche et d'un type. Invocation : `$newsit-seo`.

La version 2 ajoute un parcours de complétion, un registre de preuves, le graphe Thomas complet, les préférences documentées de Nicolas et un routage des skills. Une demande de réalisation complète autorise les choix réversibles nécessaires ; elle ne vaut pas publication ni dépense.

Entrée : SKILL.md. Suivi : assets/execution.json. Contrôle du suivi : scripts/check_execution.py chemin/registre.json. Le contrôle exige un inventaire de pages et les preuves des étapes ; il ne vérifie pas leur authenticité ni la qualité du site.
