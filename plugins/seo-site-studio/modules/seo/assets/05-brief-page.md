## Valeur propre

Ce que le lecteur gagne ; preuve originale disponible et vérifiable ; démonstration
ou données à produire ; sources ; limites ; expertise/relecture requise.
L'absence de preuve doit rester visible dans le brief, pas être rédigée comme un résultat.

## Proposition de page

Title et H1 ; description ; réponse initiale ; sections nécessaires ; exemples ;
visuels utiles et droits ; contre-indications/alternatives ; action appropriée.
La longueur découle de l'utilité. Les formulations proposées ne garantissent pas
leur affichage exact dans les résultats.

## Architecture et publication

Liens entrants/sortants ; canonical/langue ; balisage adapté au contenu visible et
à l'éligibilité actuelle ; intégration à la DA ; mobile/accessibilité ; propriétaire
et cadence de révision justifiée ; condition d'obsolescence.

## Contrôles et autorisations

Faits, prix, tests et témoignages vérifiés ; offre réellement disponible ; parcours
fonctionnel ; rendu/HTTP/meta ; mesure ; relecture ; permission de publication.
Test réussi, non réalisé et non applicable doivent être distingués.
