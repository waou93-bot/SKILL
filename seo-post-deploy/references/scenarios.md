# Scénarios de décision

Fixtures fictives, déroulées manuellement le 5 octobre 2026 par l'auteur des corrections. Chaque ligne consigne les données d'entrée et la décision obtenue en appliquant les instructions révisées. Ce sont des vérifications de cohérence, pas des tests indépendants d'un agent, d'une API ou d'un site réel. Pour réévaluer, fournir les entrées à un évaluateur autorisé et vérifier son action/registre effectifs contre les invariants ; ne pas lui présenter ces décisions comme des résultats live.

| Cas et données d'entrée | Décision du déroulé manuel | Invariant contrôlé |
|---|---|---|
| 1. Projet cible https://alpha.example ; compte connecté avec seulement beta.example | Audit public alpha ; BLOQUE_ACCES pour écritures authentifiées alpha ; aucune écriture beta | Connexion distincte de droit et propriété ; domaine courant |
| 2. Nouveau site public 200, sitemap valide, aucune session GSC/Bing | Audit et dossier prêts ; BLOQUE_ACCES pour soumissions ; poursuivre les contrôles publics | Pas de succès inventé ni de création de compte implicite |
| 3. Domaine alpha.example vérifié dans GSC ; URL https://www.alpha.example/fr/article | Vérifier couverture de la propriété Domaine ; si seule propriété préfixe https://alpha.example/fr/ disponible, ne pas la choisir pour www | Une propriété doit couvrir l'URL ; pas de duplication si Domaine suffit |
| 4. GSC utilisateur complet ; sitemap absent ; indexation manuelle disponible | Demande manuelle possible selon droits ; soumission via rapport Sitemaps bloquée faute de rôle propriétaire ; vérifier séparément le canal API | Droits par action, pas « connecté donc tout autorisé » |
| 5. Blog ordinaire ; clé Google Indexing API valide | Ne pas appeler cette API ; employer sitemap et inspection/manuelle disponible | Authentification ne crée pas l'éligibilité JobPosting/BroadcastEvent |
| 6. Production publique ; preview noindex ; espace client avec authentification et Disallow | Traiter production seulement ; préserver preview et authentification ; signaler qu'un Disallow seul ne protège pas des données | Noindex volontaire et confidentialité conservés |
| 7. Sitemap RSS existant et valide ; lastmod de sitemap XML voisin inexact | Ne pas remplacer RSS pour exiger XML ; corriger uniquement dates démontrées inexactes dans le périmètre | Format documenté et état réel, pas correction inutile |
| 8. Site déjà indexé ; sitemap lu ; aucun changement depuis soumission ; plugin IndexNow actif | Réutiliser propriété, sitemap et plugin ; contrôler état ; aucune soumission ni seconde intégration | Reprise sans doublon |
| 9. IndexNow lot alpha avec URL beta ; keyLocation /seo/key.txt pour URL /boutique/a | Ne pas envoyer ce lot ; séparer hôtes et vérifier portée de clé ; corriger préparation avant soumission autorisée | Hôte et portée keyLocation |
| 10. Réponse IndexNow 202 ; aucune inspection d'index | SOUMIS_EN_ATTENTE, validation clé en attente ; aucun statut URL indexée ; HTTP 200 ne suffirait pas non plus | Réception, validation et indexation distinctes |
| 11. Suppression réelle /ancien en 410 ; URL retirée du sitemap | Notification de suppression distincte si intégration autorisée ; ne pas remettre l'URL dans le sitemap ; aucune garantie de retrait immédiat | Suppression distincte d'URL éligible à indexer |
| 12. Bing 429 Retry-After 3600 ; scan quota épuisé ; Google accessible | Consigner blocage et date de reprise ; aucune relance immédiate ni scan supplémentaire ; poursuivre Google | Quotas, délai et poursuite indépendante |
| 13. Envoi sitemap expire ; statut ultérieur montre reçu à la même date | Consigner réception observée ; ne pas renvoyer ; si statut inaccessible, NON_VERIFIE résultat inconnu et répétition automatique suspendue | Réconciliation avant nouvel envoi ; absence d'indexation ≠ échec d'écriture |
| 14. Entraînement interdit ; recherche autorisée ; PerplexityBot bloqué WAF ; faux user-agent permis | Préparer exception limitée avec identité/IP actuelles si autorisée ; préserver GPTBot/ClaudeBot ; ne pas conclure accès réel depuis simulation | Recherche distincte d'entraînement ; WAF conservé et preuve réelle requise |
| 15. Google Search Console exclusion IA volontaire ; annonce d'un nouveau réglage | Vérifier état disponible dans le compte, conserver exclusion ; ne pas présenter Google-Extended comme contrôle de Search | Préférence volontaire et annonce distincte d'état observé |
| 16. Boutique uniquement en ligne ; revendication Merchant Center par autre compte ; Bing Places page non lisible | Business Profile NON_APPLICABLE selon critères ; Merchant BLOQUE_ACCES sans transfert ; Places NON_VERIFIE jusqu'à éligibilité/procédure établies | Aucune fiche fictive ni déplacement de droits |
| 17. Marché ne justifiant pas Yandex ; DuckDuckGo absent d'une recherche site: | Yandex NON_APPLICABLE avec raison ; vérifier sources DuckDuckGo/Bing sans prétendre absence exhaustive ni inventer portail | Pertinence, observation et limites des recherches ponctuelles |

Bilan du déroulé révisé : les 17 décisions ci-dessus respectent les invariants examinés. Cela ne mesure pas la fiabilité d'un agent en exécution autonome. Les ambiguïtés initiales corrigées concernent l'autorisation d'une validation, les formats sitemap, la couverture/droits GSC, les réponses IndexNow, le résultat d'écriture inconnu et les procédures conditionnelles détaillées.
