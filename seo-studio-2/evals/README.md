# Évaluations comportementales

Les scénarios sont préparés, **non exécutés de bout en bout** dans ce package. Unittest ne les lance
pas. Les jouer dans un environnement possédant les skills, les accès et les capacités
réelles nécessaires. Mesurer séparément bonne décision, refus indu, violation de
permission, qualité du livrable, précision des preuves et coût d'exécution.

Conserver la version du package, le modèle réellement exécuté, le prompt, les accès,
les sorties et le jugement du vérificateur. Un simple échange entre rôles simulés
n'est pas une évaluation indépendante. Le juge ne doit pas accepter « c'est fait »
sans regarder les fichiers et appels réels. Les scénarios sensibles n'autorisent
aucune publication, dépense ou action sur compte réel.

Révision du 13 octobre 2026 : les trois nouveaux cas réflexion/recherche inaccessible/reprise ont reçu une revue documentaire réelle par un sous-agent métier et des relectures après corrections. Cette revue ne constitue pas une préproduction entière exécutée. Les retours sont conservés dans le dossier de maintenance local.
