# Conflits rencontrés et décisions de conception

Ce registre résulte d'une relecture de l'auteur du package et de sources primaires,
pas d'une réunion de modèles indépendants ni d'un arbitrage externe déjà exécuté.
Les règles suivantes sont proposées au contrat SEO STUDIO 2 et à ses futurs arbitrages.

| Sujet | Tension observée | Résolution du contrat |
|---|---|---|
| Hiérarchie d'agents | la demande veut des sous-agents ; Organisation interdit les descendants exécutants | hiérarchie métier, exécution aplatie à deux délégués directs maximum |
| /personna manquant | formation exigée, dépendance non localisée | préparer les entrées ; aucune formation fictive ; transfert strict bloqué |
| Titres/meta | seo-audit fournit des fourchettes fixes | conventions d'édition et contrôle de rendu, pas obligations Google ; S02/S03 |
| FAQ | les anciennes pratiques promettent des résultats enrichis | FAQ utile au lecteur, aucune promesse de rich result ; S10 actualisé en 2026 |
| Tests mobile | seo-audit cite Mobile-Friendly Test | ne pas dépendre de l'outil retiré ; protocole navigateur/terrain, S15 |
| Structured data | extraction de texte incomplète | présence dans HTML brut possible ; absence non concluante sans rendu adapté |
| Images | lazy loading et alt ne s'appliquent pas mécaniquement à tout | distinguer image critique/hors écran, informative/décorative ; spécifier le contexte |
| Trois clics | convention pratique présentée comme universelle | objectif de profondeur contextualisé ; graphe et tâche utilisateur priment |
| Six références | deux domaines non observés | corpus partiel clairement identifié ; pas de qualités inventées |
| Tout respecter | demande de rigueur vs limites des prompts | exigences traçables + gates + tests + vérification humaine, pas garantie absolue |
| Tous les skills SEO | les phases n'ont pas le même stade | tous découverts/lus/classés ; post-déploiement préparé, non exécuté prématurément |

Les autres conseils techniques spécifiques sont revérifiés au moment de leur usage.
Aucun fichier d'un skill existant n'a été modifié par ce package.
