# SEO site preproduction — skill package

Skill package that combines the installed `design-dna` and `redaction-editoriale-web`
skills with the SEO site example in this repository. The SEO Studio 2 installer places it
beside `seo-studio-2` as the separate `seo-site-preproduction` skill. It is used for
new work and for reprises/refontes that affect architecture, experience, content or
conversion. SEO Studio 2 remains the project orchestrator when active.

The content under `assets/template-demo/` is a complete fictional sofa comparison
site. It exists as an example of page relationships and interface patterns. The
skill's first rule is to adapt every example to the niche in the user's current
request, rather than copy the sofa content or merely replace its nouns.

## Contents

- `SKILL.md` — trigger, workflow, niche adaptation rule, Studio 2 mapping and handoff checks.
- `references/preproduction-map.md` — SEO, UI/UX, prose and sales patterns to consider per niche.
- `references/seo-studio-2-integration.md` — canonical Studio deliverable mapping and integration patch.
- `references/27-template-site-preproduction.md` — Studio 2 phase-by-phase adaptation contract for G2–G5.
- `assets/template-demo/` — static illustrative site and its mandatory reuse rules.

## Dependencies

- `design-dna` for visual direction and review.
- `redaction-editoriale-web` for French editorial writing and source discipline.
- `seo-studio-2`, when it coordinates the wider project; preserve its orchestration and gates.

The package does not include the internals of those companion skills. If a required
skill is unavailable, say so and preserve the unresolved dependency in the handoff.

No automated skill evaluations were run for this package.
